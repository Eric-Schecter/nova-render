# GPU skinning verification

Production skinning runs in `model.hlsl::VSMain`. CPU animation sampling produces a matrix palette; immutable local positions, normals, joint indices and weights are uploaded only when the model is loaded. Playback APIs are unchanged.

`SkinningCSMain` calls the same HLSL `skinVertex` function for validation readback. The CPU vertex deformation oracle exists only in `tests/SkinReference.hpp`.

Mac Metal probe:

```sh
cmake -S . -B build -DNOVA_BUILD_SKINNING_PROBE=ON
cmake --build build
ctest --test-dir build -R 'skinning-gpu-metal|animation-' --output-on-failure
```

The optional probe is disabled by default. It checks 20 poses including blended joint weights, both clips, nonuniform and reflected scales; Metal API validation is enabled. Shader sources remain HLSL; MSL is generated by DXC/SPIRV-Cross.

WebGPU checks (local docs dev server on port 5173):

```sh
ctest --test-dir build -R animation-data --output-on-failure
NOVA_ANIMATION_PAGE=1 node scripts/webgpu/check-animation.mjs
```

The web test reads GPU output, compares it with the native reference, confirms bind vertices are unchanged and observes that pose changes upload only joint matrices and scene uniforms. It also checks real playback controls, pixels and hidden/mobile preview behavior. Set `NOVA_PREVIEW_URL=http://127.0.0.1:4187` to check a built static site.
