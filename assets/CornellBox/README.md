# Cornell Box

Nova 自行构建的康奈尔盒子风格示意场景：红绿侧墙、白色房间、两个旋转方块和顶部自发光面板，32 个三角形。它不是 Cornell 实验室测量数据的复刻，也不是校准参考。

几何与两张 PNG 图集嵌入 GLB，只使用一个粗糙、非金属材质，无新增依赖。发光面板通过现有 emissive 贴图实现；当前路径追踪通过反弹射线命中面板获取其照明，没有面光源重要性采样。建议配合方向光或环境光观察；极低采样下发光面照明会较噪。

推荐正面相机：yaw=0、pitch=0、distance=3.6。通过三个模型例子面板的 Model → Cornell Box 选择；相机、灯光及环境沿用当前设置，可手动调整。

重建：`node scripts/generate-cornell-box.mjs`。几何与贴图均由生成脚本构建，无外部模型署名要求。
